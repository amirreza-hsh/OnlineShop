# OnlineShop - Video Game Store

A backend project for an online video game store, built with ASP.NET Core Web API.

This is my first .NET project, and I'm developing it to practice backend development and learn more about software architecture.

## Features
- Product and category management (CRUD)
- User registration, login and logout using ASP.NET Core Identity
- Cookie-based authentication
- Shopping cart logic (in progress)
- Input validation and error handling
- Database operations using Entity Framework Core

## Technologies
- C# / ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- ASP.NET Core Identity
- Git

## Project Structure
The project is organized into four main layers:

- **API:** Controllers and HTTP endpoints
- **Application:** Services and application logic
- **Domain:** Entities and domain models
- **Infrastructure:** Database access and persistence

## Project Status
This project is still under development. Some features are implemented, while others are being completed as I continue learning .NET.
